# 🧠 World History Chatbot – Headstarter Fellowship Week 3 🚀

Sharing a milestone from our Headstarter Fellowship journey!
For **Week 3**, we (Laiba Idrees & Aliza Yousaf) built a **World History Chatbot** powered by the **RAG (Retrieval-Augmented Generation)** framework. This project combines cutting-edge tools to deliver informative and engaging responses to historical queries.

## 💡 What It Does

* Ask any history-related question
* RAG pipeline retrieves relevant historical facts
* **Gemini API** generates a conversational, contextual answer

We're continuously improving the response quality and conciseness — but we're already proud of the results! 🤩

## 🛠️ Tech Stack

* **FastAPI** – Backend API framework
* **Jinja2** – Templating engine
* **Gemini API** – Conversational response generation
* **Pinecone** – Vector database for semantic retrieval
* **TensorFlow** – ML backend support
